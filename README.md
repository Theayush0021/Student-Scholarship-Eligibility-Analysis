# Student Scholarship Eligibility Analysis 

## 📌 Project Overview

This project focuses on analyzing student information and determining scholarship eligibility using Microsoft Excel.

The workbook combines student records, program fee details, and test scores to generate a scholarship report card. Excel formulas are used to retrieve relevant information and automatically classify students based on their test performance.

## 📂 Workbook Structure

The Excel workbook contains four worksheets:

1. **Scholarship Test Report Card** – Displays student details, program codes, program fees, test scores, and scholarship eligibility status.
2. **Students** – Contains student information, including university ID, name, program code, major, enrollment type, and residence hall.
3. **Fees** – Contains program codes and their corresponding fees.
4. **TestScores** – Contains student IDs, names, and test scores.

## 🎯 Project Objectives

- Combine student information from multiple worksheets.
- Retrieve program codes using student IDs.
- Fetch program fees based on program codes.
- Retrieve student test scores.
- Determine scholarship eligibility based on test performance.
- Generate an organized scholarship report card.

## 🛠️ Excel Skills & Functions Used

- XLOOKUP
- IF Function
- Lookup and Reference Functions
- Logical Functions
- Cross-Sheet Data Retrieval
- Data Organization
- Formula-Based Automation

## 📊 Scholarship Eligibility Criteria

The project uses the following eligibility condition:

- **Eligible:** Test Score >= 70
- **Not Eligible:** Test Score < 70

The IF function automatically determines the scholarship status based on the test score.
